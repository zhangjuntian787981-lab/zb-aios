# Build the generic product before enterprise onboarding

P0 through P2 build and verify a reusable multi-enterprise product using only Synthetic Fixtures; P3 is the first phase that accepts internal enterprise information, Enterprise Users, or live Connector Instances, and those inputs are still admitted incrementally inside P3. Public Enterprise Context must remain separate from Product Core data, Synthetic Fixtures, evaluation truth, and release packages; a Synthetic Tenant is never upgraded in place to a real Tenant. This keeps early delivery independent of one company, supports product packaging for other enterprises, and makes the external Product Owner the sole project-stage approver without granting that role enterprise data or runtime authority.
