# Bind every stage-gate decision to an immutable submission

Each attempt to pass G0, G1, G2, or G3 is an immutable Gate Submission whose canonical Frozen Evidence Package has a content hash, and the Product Owner records exactly one immutable Gate Decision for that submission. Returned or held work is resubmitted under a new hash; changed evidence invalidates an earlier approval for opening the next phase; exclusions cannot waive required work packages or zero-tolerance conditions, and this product-stage mechanism remains separate from Tenant runtime authorization.
